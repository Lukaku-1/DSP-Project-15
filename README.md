# DTMF Real time communication system using ESP32

## Description

PBECT504 Digital Signal Processing course project for B.tech Electronics and Communication Engineering @ College of Engineering Trivandrum (CET)
Done by Team 15 (Akul S Mohan, Rohann Subhash, Samil R, Sandeep Santhosh K)

## About
A Hardware based Dual Tone Multi-Frequency (DTMF) signal transmitter and receiver implemented using ESP32. Filtering of noisy signal after transmission done using Goertzel Algorithm. Further details to be added

## Componants 

## Transmitter
1x ESP32 Dev board
1x MAX98357A Amplifier
1x 4x4 Matrix Keypad
1x 10W 4ohm speaker

## Receiver
1x ESP32 Dev board
1x INMP441 MEMS Mic Module
1x O.96 inch OLED Display

## Miscellaneous
Jumper Wires
Breadboard
Single core wire
Protoboard
